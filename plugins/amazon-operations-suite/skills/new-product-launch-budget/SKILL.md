# 新品 Launch 预算预测 Skill

中文名称：新品 Launch 预算预测  
English name: `new-product-launch-budget`

## 使用目标

帮助用户判断新品是否推得起，估算首月和前 90 天预算、日预算、广告亏损上限、库存需求和关键前置条件。

## 触发场景

在以下情况使用本 skill：

- 用户想知道新品首月或前三个月要准备多少钱。
- 用户已有关键词、目标排名、竞品销量、价格和利润，想判断推不推得起。
- 用户需要比较保守、基准、激进三档 Launch 方案。

不适合使用本 skill 的情况：

- 用户还没确定产品方案，应先用 `product-differentiation-planner`。
- 用户还没测算单件利润，应先用 `profit-cost-estimator`。
- 用户没有关键词、CPC、CVR 或竞品销量时，只能输出预算区间和待补数据。

## 必需输入

- `marketplace`：站点；未提供时可按 US 预分析，并标注“站点待确认”。
- `target_keywords`：目标关键词。
- `target_rank`：目标排名。
- `competitor_sales`：竞品销量。
- `expected_cpc`：预期 CPC。
- `expected_cvr`：预期 CVR。
- `selling_price`：售价。
- `unit_profit_before_ads`：广告前单件利润。
- `launch_period_days`：Launch 周期。
- `inventory_units`：库存数量。

## 可选数据源

- 广告结构、自然排名目标、Review 目标、优惠券、站外预算、库存成本。
- 卖家精灵、Sorftime 获取关键词、竞品销量和 CPC；未开启时要求用户提供表格或截图。

## 数据要求

分析前先做数据完整性检查，并在输出开头写清“已满足 / 缺失 / 只能区间预测”。

| 数据项 | 最低要求 | 缺失时处理 |
|---|---|---|
| 站点 | 明确站点；未指定时只能按 US 预分析 | 标注“站点待确认” |
| 目标关键词 | 关键词列表和优先级 | 不能判断目标排名和流量 |
| 目标排名 | 希望进入的自然位或广告位 | 只能输出通用预算框架 |
| 竞品销量 | 目标竞品日销或月销 | 不能估算目标日单 |
| CPC | 关键词预期 CPC 或区间 | 只能输出广告预算区间 |
| CVR | 预期转化率或类目参考 | 不能估算点击到订单 |
| 售价 | Launch 售价 | 不能估算收入和优惠券影响 |
| 广告前利润 | 单件广告前利润 | 不能计算广告亏损上限 |
| 周期 | 首月或 90 天周期 | 默认输出首月和 90 天，但标注假设 |
| 库存 | 可用库存和补货周期 | 必须提示断货风险，不能判断推得起 |

CPC、CVR、竞品销量缺失时必须输出区间，不输出伪精确数字。

## MCP 开启约束

- 卖家精灵/Sorftime 可用于获取关键词、竞品销量和 CPC；使用前必须先确认已开启。
- MCP 未开启时，不要编造关键词 CPC、竞品销量、转化率、市场容量或排名难度；要求用户提供表格、截图或历史广告数据。
- 用户表格和 MCP 数据冲突时，分开做口径说明和两套预算，不强行合并。
- 外部数据必须标注来源、站点、时间和是否估算。
- 预算预测不是排名保证，不能把工具返回值直接写成确定结果。

## 工作流

1. 先做数据完整性检查和 MCP 开启检查；缺少 CPC、CVR、竞品销量或利润时降级为区间预测。
2. 明确站点、关键词、竞品销量、目标排名、售价、广告前利润和库存。
3. 估算目标日单和首月订单需求。
4. 根据 CPC 和 CVR 估算广告点击量、订单量和广告花费。
5. 结合单件利润，计算广告亏损期、现金流压力和回本周期。
6. 加入优惠券、Review 积累、库存周转、补货周期和站外预算。
7. 输出保守、基准、激进三档 Launch 预算。

## 输出合同

用中文输出。三档预算和方案对比必须用表格，并说明优劣势。必须包含：

| 模块 | 必填内容 |
|---|---|
| 数据状态 | 已用数据源、MCP 是否开启、缺失字段、预算口径 |
| 是否推得起 | 能推、谨慎推、不要推、需要更多数据 |
| 首月预算 | 广告、优惠券、站外、库存占用、预估亏损 |
| 前 90 天预算 | 分月预算、回本周期、现金流压力 |
| 日预算建议 | 保守、基准、激进三档日预算 |
| 广告亏损上限 | 单日和整个 Launch 周期可承受亏损 |
| 库存需求 | 首月销量、90 天销量、补货节点、断货风险 |
| 关键前置条件 | Listing、Review、价格、库存、广告结构 |
| 缺失输入 | CPC、CVR、竞品销量、排名目标、利润、库存 |
| 下一步 skill | 差异化调整、利润复算或供应链确认 |

内部可使用统一字段：

```json
{
  "verdict": "go | cautious | no-go | need-more-data",
  "confidence": "high | medium | low",
  "key_findings": [],
  "risks": [],
  "action_items": [],
  "missing_inputs": [],
  "next_skill": ""
}
```

## 风险规则

- 预算是预测，不是排名保证。
- CPC、CVR、竞品销量缺失时必须输出区间，不输出伪精确数字。
- 必须提醒库存断货会破坏 Launch 节奏。
- 不要把短期广告亏损当作必然可回收，必须写清回本条件。
- 不要只看广告费，必须包含优惠券、库存、补货周期和现金流压力。

## 下一步

- 如果预算超过承受能力，返回 `product-differentiation-planner` 调整方案或价格带。
- 如果利润口径不清，进入 `profit-cost-estimator` 复算。
- 如果库存或交期影响 Launch，进入 `supply-chain-feasibility-review`。
