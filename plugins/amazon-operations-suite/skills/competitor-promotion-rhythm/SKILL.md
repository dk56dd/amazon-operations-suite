# 竞品推广节奏

## 核心原则

先判断 MCP 接入，再判断推广节奏。只识别风险，不提供刷单、黑科技、违规操纵的执行方法。

本 Skill 用于判断竞品增长是否健康，包括评分、评论、销量、BSR、价格、Coupon、广告强度、变体、上架时间、差评变化和异常增长信号。

## 第 0 步：MCP 接入检查

开始前必须判断当前 agent 是否能调用：

- `SIF MCP` / `sif mcp`
- `卖家精灵 MCP` / `sellersprite mcp`

检查方式：

- 若当前会话已暴露 MCP 工具，直接检查工具名称和能力。
- 若支持 `tool_search`，优先搜索 `sif`、`sellersprite`、`卖家精灵`。
- 不要编造未暴露工具。

按结果分流：

- 两者都不可用：先告诉用户“当前未检测到 SIF / 卖家精灵 MCP 接入，只能用联网公开信息判断推广节奏，销量、评论增速、广告强度和异常玩法识别会有明显误差”。然后走联网低置信分析。
- 只有 SIF 可用：以流量和广告变化为主，评论/销量风险用公开信号补充。
- 只有卖家精灵可用：以销量、BSR、价格、评论、评分趋势为主，广告节奏只能推断。
- 两者都可用：用卖家精灵判断增长结果和评论风险，用 SIF 判断流量/广告驱动。

## 第 1 步：识别输入

根据用户输入选择分析路径：

- 单个 ASIN：做完整推广节奏和风险识别。
- 多个 ASIN：横向比较谁是正规增长、谁可能有异常玩法。
- 关键词/类目：先识别近期增长最快竞品，再做节奏拆解。
- 新品：重点看上架时间、首评速度、排名爬坡、广告/促销密度。
- 老品：重点看评论结构、价格变化、排名稳定性、复购和自然流量。

若用户未给 ASIN，最多追问一次要 ASIN/关键词/类目；也可以先基于关键词做竞品池初筛。

## 第 2 步：卖家精灵 MCP 节奏链路

卖家精灵 MCP 可用时优先抓：

- ASIN 基础信息：上架时间、品牌、类目、价格、变体。
- 销量/销售额趋势：日、周、月趋势与异常尖峰。
- BSR / 类目排名趋势：排名爬升速度和稳定性。
- Review 数量、评分、评论增速、差评率。
- Coupon、秒杀、Prime、价格波动。

重点判断：

- 评论增长是否和销量增长匹配。
- 排名爬升是否和广告/促销/价格变化匹配。
- 评分是否异常稳定，差评是否被稀释。
- 变体是否可能承担引流、合并评论或转移差评风险。

## 第 3 步：SIF MCP 节奏链路

SIF MCP 可用时优先看：

- `asinOpTrafficTrend`：先看 ASIN 流量趋势。
- `asinOpTrafficTrendDetail`：下钻异常日期/周的关键词变化。
- `ads_get_asin_ad_structure`：看广告规模和结构。
- `ads_get_asin_ad_traffic_trend`：看广告流量是否解释销量/排名变化。
- `ads_get_asin_campaign_changes`：看 Campaign 调整是否对应推广节点。
- 必要时继续下钻 Campaign、AdGroup、Keyword。

判断逻辑：

- 若广告流量上升、自然排名随后承接，偏正规推广。
- 若排名/评论突增但广告和自然关键词没有对应变化，标记为异常待核验。
- 若单个词突然大幅贡献流量，检查是否是大词强推、低价促销或站外活动。

## 第 4 步：无 MCP 的联网兜底

无 MCP 时必须先输出风险提示：

```text
当前未检测到 SIF / 卖家精灵 MCP 接入。下面只能用联网公开信息判断推广节奏，销量、评论增速、广告强度和异常玩法识别会有明显误差，结论只能作为风险初筛。
```

可用公开信号：

- Amazon 前台价格、Coupon、Prime、变体、类目排名、评论数、评分。
- 评论时间分布、评论图片/视频、差评主题、重复表达。
- 搜索结果页 Sponsored 曝光、商品页广告位、品牌内容完整度。
- 站外测评、社媒、Deal 网站、品牌官网活动。

无 MCP 时不要输出精确销量、精确日评论增量、精确广告花费。

## 第 5 步：推广节奏判断框架

每次至少覆盖 8 个维度：

1. 上架阶段：新品冷启动、爬坡期、稳定期、衰退期、二次拉升。
2. 销量/排名节奏：平滑增长、阶梯增长、尖峰增长、断崖下滑。
3. 评论/评分节奏：评论增速、评分波动、差评稀释、首评速度。
4. 广告节奏：广告结构、广告流量、关键词贡献、广告位倾向。
5. 价格/促销：降价、Coupon、秒杀、会员活动、清库存。
6. 变体策略：变体新增、父子体合并、评论迁移风险。
7. 转化承接：Listing、A+、视频、图片、QA、差评处理。
8. 风险类型：正规玩法、激进但合规、疑似异常、明显高风险。

## 第 6 步：异常玩法风险识别

只做风险识别，不提供操作方法。

### 偏正规玩法

常见信号：

- 销量、BSR、广告流量和评论增长方向一致。
- 评论增长滞后于销量，评分有自然波动。
- 关键词排名逐步提升，有促销或广告解释。
- 差评存在但被产品优化或客服改进逐步稀释。

### 激进但可能合规

常见信号：

- 短期大额广告强推。
- 明显降价、Coupon、Deal 配合。
- 站外流量或红人测评带来尖峰。
- 评价增长快但仍能被销量和活动解释。

### 疑似刷单 / 评论操纵风险

常见信号：

- 评论数短期异常增长，但销量/排名/流量无对应变化。
- 大量评论集中在短时间窗口，措辞高度相似。
- 评分长期异常稳定，差评很快被大量好评淹没。
- 低销量阶段已有不合理数量评论。
- 评论地域、图片、视频、关键词表达异常一致。

### 疑似黑科技 / 高风险玩法

常见信号：

- 排名突升但广告、价格、促销、站外活动都无法解释。
- 变体频繁新增/合并后评论结构突变。
- 类目节点、标题、品牌、变体关系频繁异常变化。
- 竞争对手短期获得大量不符合生命周期的信任资产。

输出时使用“疑似”“需要进一步核验”，不要定性为事实，除非工具数据直接证明。

## 第 7 步：输出格式

第一句直接给判断：

```text
这个竞品当前属于【正规推广 / 激进合规 / 疑似异常 / 高风险玩法】节奏，核心证据是……
```

推荐结构：

```markdown
这个竞品当前属于……，我们应采取……策略。

**节奏证据**
- 销量/BSR：……
- 评论/评分：……
- 广告/流量：……
- 价格/促销：……
- 变体/Listing：……

**风险判断**
- 正规信号：……
- 异常信号：……
- 仍需核验：……

**我们怎么应对**
- 如果正规增长：……
- 如果激进合规：……
- 如果疑似异常：……
- 不建议跟随的动作：……

**置信度**
- 数据来源：SIF / 卖家精灵 / 联网公开信息
- 数据缺口：……
- 把握程度：高 / 中 / 低
```

## 第 8 步：应对策略

根据判断给策略：

- 正规推广：拆它的关键词、广告结构、转化承接，找可复制动作。
- 激进合规：避开正面硬刚，找低竞争长尾词、差评痛点和细分场景。
- 疑似异常：不要跟随异常节奏；用合规广告、站内转化和产品差异化慢打。
- 高风险玩法：记录风险，不建议模仿；关注平台政策、投诉证据和合规防守。

## 质量红线

- 不提供刷单、测评操纵、恶意攻击、变体滥用、黑帽排名的操作教程。
- 不把“疑似异常”说成确定事实。
- 不在无 MCP 时编造销量、评论增速、广告成本。
- 不只看评论数量，必须结合销量、排名、广告、价格和时间。
- 不忽略站点差异；用户未指定时默认 US。
