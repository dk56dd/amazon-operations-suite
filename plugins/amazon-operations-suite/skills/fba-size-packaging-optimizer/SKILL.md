# FBA 尺寸与包装优化 Skill

中文名称：FBA 尺寸与包装优化  
English name: `fba-size-packaging-optimizer`

## 使用目标

帮助用户在开发阶段发现包装尺寸、重量和套装方案的费用临界点，降低 FBA 和物流成本，同时避免牺牲用户体验或增加破损率。

## 触发场景

在以下情况使用本 skill：

- 用户想优化包装尺寸、重量和 FBA 费用。
- 用户问“这个产品尺寸会不会亏”“包装能不能压缩”“套装几个最合适”。
- 用户要比较单件、多件套、折叠、真空、分体包装等方案。

不适合使用本 skill 的情况：

- 用户只关心整体利润模型，应使用 `profit-cost-estimator`。
- 用户需要判断认证要求，应使用 `compliance-certification-scanner`。
- 用户没有尺寸、重量或包装方案时，只能输出打样和测量框架。

## 必需输入

- `marketplace`：站点；未提供时必须标注“站点待确认”。
- `product_size`：产品裸机尺寸。
- `package_size`：单件包装尺寸。
- `product_weight`：单件重量。
- `shipping_box_size`：外箱尺寸。
- `units_per_carton`：装箱数量。
- `bundle_options`：可选套装方案。

## 可选数据源

- 最新 FBA 尺寸分段表、竞品尺寸、供应商包装方案、物流报价。
- FBA 费用表或用户提供的官方费用截图。费用口径不明时只做方向性判断。

## 数据要求

分析前先做数据完整性检查，并在输出开头写清“已满足 / 缺失 / 只能方向性优化”。

| 数据项 | 最低要求 | 缺失时处理 |
|---|---|---|
| 站点 | 目标站点，例如 US、CA、UK、DE、JP | 无站点时不输出精确费用 |
| 类目或费用口径 | FBA 尺寸分段表或用户提供费用表 | 无费用表时只判断压缩方向 |
| 裸机尺寸 | 长、宽、高和单位 | 不能判断结构压缩空间 |
| 包装尺寸 | 长、宽、高和单位 | 不能判断 FBA 尺寸段 |
| 单件重量 | 产品加包装重量和单位 | 不能判断重量段 |
| 外箱信息 | 外箱尺寸、装箱数量 | 不能判断头程和装箱效率 |
| 套装方案 | 单件、多件套或候选组合 | 无套装方案时只优化单件包装 |

尺寸和重量必须写单位。单位不清时先要求确认，不要混用 inch、cm、lb、kg。

## MCP 开启约束

- 本 skill 不强制 MCP；可以使用用户提供的最新 FBA 费用表、官方截图或手工表。
- 如果用户要求通过外部费用表、FBA fee API、Sorftime 或卖家精灵补充竞品尺寸/费用，必须先确认相关 MCP 或数据源已开启。
- MCP 或费用表未开启时，不要编造尺寸分段、FBA 费或竞品包装数据。
- 没有站点、类目、费用表时，只能输出包装优化方向和待补字段，不输出确定金额。
- 外部费用数据要标注来源、站点、类目和日期口径。

## 工作流

1. 先做数据完整性检查和费用来源/MCP 开启检查；不满足时停止精确费用判断。
2. 确认站点、类目、产品裸机尺寸、包装尺寸、重量和外箱信息。
3. 判断当前包装可能落入的 FBA 尺寸/重量段，并标注数据口径。
4. 找出临界点：长、宽、高或重量是否只差一点就进入更低费用段。
5. 分析压缩、折叠、真空、拆件、配件内嵌、说明书压缩、套装数量变化的影响。
6. 比较每个方案的费用节省、用户体验、破损风险、供应链难度和打样成本。
7. 输出供应商可执行的打样检查清单。

## 输出合同

用中文输出，方案对比必须用表格并说明优劣势。必须包含：

| 模块 | 必填内容 |
|---|---|
| 数据状态 | 已用尺寸重量、费用表/MCP 是否开启、单位、缺失字段 |
| 当前尺寸费用判断 | 当前包装可能处于的尺寸/重量段，数据口径和置信度 |
| 临界风险 | 哪个尺寸或重量最危险，差多少进入更优区间 |
| 包装优化方案 | 方案、改动点、预期节省、体验影响、破损风险、供应链难度 |
| 套装建议 | 单件、多件套或组合装的优劣势 |
| 打样检查清单 | 尺寸测量、跌落测试、开箱体验、配件完整性、条码和标签 |
| 缺失输入 | 需要补充的站点、类目、费用表、尺寸重量字段 |
| 下一步 skill | 利润测算或供应链可行性评估 |

内部可使用统一字段：

```json
{
  "verdict": "go | cautious | no-go | need-more-data",
  "confidence": "high | medium | low",
  "key_findings": [],
  "risks": [],
  "action_items": [],
  "missing_inputs": [],
  "next_skill": ""
}
```

## 风险规则

- 不要只为省 FBA 费牺牲用户体验或增加破损率。
- 没有站点、类目和费用表时，不输出确定费用。
- 包装建议必须能落到供应商打样要求，不能只写“压缩包装”。
- 对临界尺寸必须提醒实际测量误差、纸箱公差和平台复测风险。
- 不要把费用节省直接当成净利提升，仍需进入利润模型验证。

## 下一步

- 如果节省金额影响净利，进入 `profit-cost-estimator` 重新测算。
- 如果需要确认供应商能否实现包装改动，进入 `supply-chain-feasibility-review`。
- 如果包装涉及标签、警告语或认证标识，进入 `compliance-certification-scanner`。
