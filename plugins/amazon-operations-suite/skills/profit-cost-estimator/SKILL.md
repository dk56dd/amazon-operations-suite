# 利润与成本测算 Skill

中文名称：利润与成本测算  
English name: `profit-cost-estimator`

## 使用目标

帮助用户判断新品是否具备可开发利润空间，并反推采购价上限、售价下限、盈亏平衡 ACOS 和关键敏感变量。

## 触发场景

在以下情况使用本 skill：

- 用户想判断新品是否赚钱。
- 用户提供采购价、售价、尺寸、重量、广告成本，想算净利率和盈亏边界。
- 用户需要比较多个产品方案或多个价格带的利润优劣势。

不适合使用本 skill 的情况：

- 用户只想挖评论痛点，应使用 `review-painpoint-mining`。
- 用户主要关心包装尺寸是否可压缩，应使用 `fba-size-packaging-optimizer`。
- 用户要判断认证或上架风险，应使用 `compliance-certification-scanner`。

## 必需输入

- `marketplace`：站点；未提供时必须标注“站点待确认”。
- `selling_price`：目标售价。
- `purchase_cost`：采购价。
- `shipping_cost`：头程或单件物流成本。
- `fba_fee`：FBA 费用。
- `referral_fee_rate`：佣金比例。
- `expected_acos`：预期广告 ACOS。
- `return_rate`：退货率。
- `target_margin`：目标净利率。

## 可选数据源

- 优惠券、站外折扣、仓储费、长期仓储费、汇率、VAT、平台费用变化。
- FBA fee API、卖家精灵、Sorftime 或用户手工表。费用表可能随站点、类目和时间变化，必须标注数据口径。

## 数据要求

分析前先做数据完整性检查，并在输出开头写清“已满足 / 缺失 / 只能区间测算”。

| 数据项 | 最低要求 | 缺失时处理 |
|---|---|---|
| 站点 | 明确站点和币种 | 标注“站点待确认”，费用不输出精确值 |
| 售价 | 目标售价或售价区间 | 只能反推目标售价，不能给净利率结论 |
| 采购价 | 工厂报价或目标采购价 | 只能反推采购价上限 |
| 重量和包装尺寸 | 用于 FBA 和头程判断 | 不能判断 FBA/FBA 临界费用 |
| 头程 | 单件头程或可换算的物流报价 | 只能做缺口测算 |
| 佣金 | 类目佣金率或用户给定比例 | 不得假设类目佣金为固定值 |
| FBA 费 | 当前站点、尺寸、重量对应费用 | 不得输出精确净利 |
| 广告 ACOS | 预期 ACOS 或区间 | 必须输出广告前利润和广告后未知项 |
| 退货率 | 类目或历史退货率 | 标注退货损耗缺失，降级置信度 |

费用缺失时可以做“反推模型”或“区间模型”，但不能写成确定利润。

## MCP 开启约束

- 本 skill 不强制 MCP；优先使用用户给定费用表和成本字段。
- 如果用户要求用 FBA fee API、卖家精灵或 Sorftime 获取费用、竞品价格、CPC、销量等数据，必须先确认相关 MCP 或数据源已开启。
- MCP 未开启时，不要编造 FBA 费、佣金、竞品售价、广告 ACOS、汇率或 VAT；必须列出待开启数据源或待补字段。
- FBA 费、佣金、汇率、VAT、平台费用可能随站点、类目和日期变化；任何外部数据都要标注来源和日期口径。
- 用户手工表与 MCP 数据冲突时，优先保留两套口径分别测算，不要强行合并。

## 工作流

1. 先做数据完整性检查和 MCP/费用来源检查；缺失关键费用时降级为区间测算或反推模型。
2. 计算基础毛利：售价 - 采购 - 头程 - FBA - 佣金。
3. 加入广告成本，计算广告后净利和净利率。
4. 加入退货、优惠券、仓储和不可预见损耗。
5. 输出乐观、基准、保守三档情景。
6. 反推可接受采购价、可接受 ACOS、最低售价和首批备货风险。

## 输出合同

用中文输出。涉及对比时必须用表格，并同时说明优劣势。必须包含：

| 模块 | 必填内容 |
|---|---|
| 数据状态 | 已用费用来源、MCP 是否开启、费用口径、缺失字段 |
| 是否可开发 | `可做`、`谨慎做`、`放弃`、`需要更多数据` |
| 单件利润表 | 售价、采购、头程、FBA、佣金、广告、退货、优惠券、仓储、净利 |
| 三档情景 | 乐观、基准、保守的利润、净利率、关键假设 |
| 盈亏平衡 ACOS | 当前成本结构下最高可承受 ACOS |
| 采购价上限 | 达到目标净利率时的最高采购价 |
| 售价下限 | 不亏损和达到目标净利率的价格线 |
| 广告亏损承受区间 | Launch 初期可承受亏损和回本条件 |
| 关键敏感项 | 哪个变量最影响利润 |
| 缺失输入 | 影响精确度的字段 |
| 下一步 skill | FBA 尺寸包装、供应链可行性或 Launch 预算 |

内部可使用统一字段：

```json
{
  "verdict": "go | cautious | no-go | need-more-data",
  "confidence": "high | medium | low",
  "key_findings": [],
  "risks": [],
  "action_items": [],
  "missing_inputs": [],
  "next_skill": ""
}
```

## 风险规则

- 不要只看毛利，必须包含广告和退货。
- 费用缺失时必须列出待补字段，不要输出伪精确结果。
- 汇率、FBA 费、佣金、VAT 可能随站点和类目变化，必须标注数据口径。
- 不要把短期促销价当作长期售价。
- 不要把“利润为正”直接等同于“可以开发”，仍需检查竞争、合规、供应链和 Launch 成本。

## 下一步

- 如果 FBA 费用或尺寸临界影响利润，进入 `fba-size-packaging-optimizer`。
- 如果采购价目标不确定，进入 `supply-chain-feasibility-review`。
- 如果需要判断推不推得起，进入 `new-product-launch-budget`。
