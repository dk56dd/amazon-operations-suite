# Amazon Monthly Operations Report / 亚马逊运营月报分析

## 名称、视角与范围

- English name: **Amazon Monthly Operations Report**
- 中文名称：**亚马逊运营月报分析**
- 触发词：亚马逊月报、Amazon monthly report、月度经营分析、月度广告复盘、月度库存/利润分析、下月经营计划。

两个视角必须分开：

| 视角 | 核心问题 | 必须产出 |
|---|---|---|
| 运营执行视角 | 哪些产品、广告、Listing、库存动作解释了本月，下一月具体怎么改 | 有证据的修复、扩量、补货和内容动作，负责人、截止时间、验收指标、停止条件 |
| 管理决策视角 | 目标、贡献、现金、库存和产品组合是否健康，资源投向哪里 | 目标差距、利润/现金/库存暴露、产品组合、资源配置、升级和拍板事项 |

只做分析和建议，不自动修改广告、价格、库存、Listing、预算、数据库或外部系统。

## 1. 完整数据源前置闸门

以下任一完整路径实际可用后才允许分析：

| 数据源路径 | 完整条件 | 优势 | 局限 |
|---|---|---|---|
| 上传报告 | 同一站点同时有业务报告和广告报告，覆盖目标月份 | 原始文件可审计，可归档 | 字段、日期粒度和归因定义可能不同 |
| 领星 MCP | 调用成功，业务和广告两侧均返回目标月份非空数据 | 可重复读取并可能提供库存明细 | 受权限、账户范围和数据新鲜度影响 |
| 优麦云 MCP | 调用成功，业务和广告两侧均返回目标月份非空数据 | 可复用集中经营数据 | 字段和财务语义可能与报告不同 |

仅开启 MCP 不足以通过闸门，必须探测实际数据。无完整路径时立即停止并输出：

`无法开始月报分析：尚未发现可用的完整数据源。`

列出缺少的业务报告、广告报告、领星 MCP 或优麦云 MCP，并说明下一步需要提供什么。只有一份报告时不做完整月报，不把广告销售额或广告订单当成总销售和总订单。多个来源默认优先上传报告、领星 MCP、优麦云 MCP，不静默合并重叠数据。

## 2. 月份与站点时间

使用站点本地时区和本地自然月，记录账户、站点、币种、时区、父子 ASIN/SKU 粒度、来源生成时间、请求月份和实际覆盖率。无法确认时区时标记 `时区未确认`，不自行猜测。

| 窗口 | 定义 | 用途 |
|---|---|---|
| 本月截至今日 | 本地月初至今日 | 运营脉搏，必须标记部分月 |
| 上月完整月 | 上一个本地自然月 | 默认主要月度复盘 |
| 近三个月 | 当前月前的三个完整自然月 | 趋势、波动和资源背景 |
| 同比月 | 去年同一自然月，有可比数据才展示 | 季节性和年度趋势 |
| 年初至今 | 本地年初至今日或指定月末，有覆盖才展示 | 管理层累计视角 |

用户指定月份时以指定月份为主，与上个完整月和去年同月比较。当前月未结束时，按已过去的本地天数与上月同期比较，同时展示实际值和日均/预计速度；不能把本月累计和上月完整月直接当成同等周期。不同站点、币种、时区不直接合并。

## 3. 字段与计算口径

标准字段：`site`、`local_date`、`product_key`、`ASIN/SKU`、`sales_amount`、`currency`、`units`、`orders`、`ad_spend`、`ad_orders`、`ad_sales`、`sellable_units`、`reserved_units`、`inbound_units`、`inventory_timestamp`。可选字段：退货、退款、平台费、仓储费、配送费、COGS、单位成本、库存价值、目标、广告预算、补货周期、安全库存、Listing 状态和库存年龄。

| 指标 | 公式/取值 | 使用规则 |
|---|---|---|
| 销售额/销量/订单数 | 业务字段按月求和 | 说明 ordered 或 shipped |
| 日均销售/销量/订单 | 期间总量 ÷ 实际覆盖本地天数 | 支持本月与同期速度比较 |
| 广告费/广告订单/广告销售额 | 广告字段按月求和 | 保留归因窗口和币种 |
| 广告花费占比 / TACoS | 广告费 ÷ 业务销售额 | 分母为零时 N/A |
| 广告订单占比 | 归因广告订单 ÷ 业务订单 | 不与业务订单相加 |
| ACOS | 广告费 ÷ 广告销售额 | 无广告销售额时 N/A，与 TACoS 分开 |
| MoM/YoY |（本月 - 可比期间）÷ 可比期间 | 比率变化用百分点 |
| 目标达成率 | 实际 ÷ 用户提供目标 | 无目标时 N/A |
| 预算消耗率 | 实际广告费 ÷ 用户提供预算 | 无预算时不判断超支/节省 |
| 贡献/利润 | 销售额 - COGS - 平台费 - 广告费 - 退款等已提供成本 | 只有口径和期间完全对齐才计算 |
| 期末库存 | 最新有效本地库存快照 | 不跨日相加 |
| 库存可售天数 | 期末可售库存 ÷ 近期日均销量 | 估算；在途单列 |

缺失、空白、零和不适用严格区分；缺失不填零。不同币种、ordered/shipped、广告归因日期、成本期间不一致时分别展示。没有成本不能声称利润，没有单位成本或库存价值不能推算现金占用，库存年龄缺失时只能称月度滞销信号。

## 4. 运营执行视角

1. 将月份拆为周或日期带，找出变化发生的时间，不能用月度总量掩盖月末断货。
2. 用销量、销售额、广告依赖、流量和转化字段解释产品变化；无字段则写待验证假设。
3. 按月销量详细分析前五和最差五产品，比较上月排名、贡献、广告依赖和库存。
4. 按广告费、广告订单、TACoS、ACOS及词/位置数据识别扩量机会和浪费信号。
5. 复核补货、断货天数、在途时间、滞销库存和 Listing 可售状态。

每项运营动作必须包含站点/产品、证据、动作、负责人角色、截止时间、验收指标和停止条件。低排名不能单独证明产品应退出。

## 5. 管理决策视角

用表格展示：

- 销售额、销量、订单、广告费、TACoS/ACOS、库存与用户目标的实际值、差距、达成率和 MoM/YoY。
- 只有销售、COGS、平台费、退款、广告费等成本在同一站点、币种和期间对齐时，才输出利润/贡献桥。
- 有单位成本或库存价值时展示现金及库存占资；不能用售价替代成本。
- 产品组合分为扩量、维持、整改、减少资源、新品测试或退出候选，写出需求、效率、利润、库存和风险证据。
- 展示头部产品/站点集中度、广告依赖、断货暴露和单一产品/站点依赖。
- 比较广告预算、补货、Listing/内容、人力和新品测试资源，必须写资源取舍。
- 对需要管理层批准的事项列出选项、推荐、预期收益、下行风险、负责人和决策截止时间。

没有目标或成本时，只输出趋势、效率信号、库存/现金中有数据支持的部分和经营风险，不声称已完成 ROI 或利润结论。

## 6. 风险与升级

使用 P0 同日升级、P1 下个运营周期、P2 监控。每条风险包含等级、范围、触发证据、影响、动作、负责人、复核时间和数据限制。

| 风险 | 证据 | 处理 |
|---|---|---|
| 断货/服务损失 | 月内有需求时可售库存为零、存在断货天数，或期末可售天数低于补货周期加安全库存 | 补货/调拨、保护剩余需求、复核广告曝光并升级 ETA |
| 滞销/库存占资 | 有库存但月销量为零、速度弱或可售天数大于 30 天；有库存年龄时优先使用年龄 | 减少入库、促销/组合、清库存复核，并在有成本时量化库存价值 |
| 广告效率恶化 | TACoS/ACOS 差于目标或可比期，或有花费无归因订单 | 词/位置诊断、预算重分配和带护栏测试 |
| 利润/现金风险 | 贡献下降、费用/退款上升，或库存价值增长而售罄速度变弱 | 重建利润桥，冻结低回报花费/入库并升级决策 |
| 集中度风险 | 少数产品/站点承担较大份额且存在库存、Listing 或广告依赖 | 建立备选组合与产能计划，不使用未说明的任意阈值 |
| 数据异常 | 月份覆盖不全、混币种、重复粒度、负数、成本期间错位 | 仅排除受影响计算，展示具体缺口 |

## 7. 固定输出结构

```text
# 亚马逊运营月报分析｜站点/账户｜报告月
## 0. 管理层摘要
目标/趋势、广告效率、利润/现金、库存、组合变化、需拍板事项 5-8 条。
## 1. 数据源、范围与口径
来源、站点、币种、时区、月份、覆盖率、粒度、完整性、优势、局限表。
## 2. 月度核心经营指标
本月截至今日、上月完整月、近三个月、同比月、年初至今；销售、销量、订单、日均、广告费、TACoS、广告订单、广告订单占比、广告销售额、ACOS、目标、达成率、期末库存、可售天数、MoM/YoY。
## 3. 月内节奏与经营原因
按周/日期带拆解销售、广告、库存和异常；区分事实、原因、假设、待验证项。
## 4. 销量前五与最差五产品
月销量排名和逐产品事实-判断-动作表，比较上月贡献与广告依赖。
## 5. 运营执行复盘
产品、广告、Listing、库存、供应链：动作、负责人、验收指标、停止条件。
## 6. 管理层经营判断
目标、利润/现金、库存占资、集中度、组合、资源和拍板事项。
## 7. 风险与升级清单
P级、风险、范围、证据、影响、动作、负责人、时间、数据限制。
## 8. 下月经营计划
目标、预算/资源假设、动作、负责人、验收指标、停止条件。
## 9. 数据质量与待补字段
只列影响结论的缺口。
```

资源竞争时，补充 `资源分配的优势与局限` 表，解释排序为何保护增长、贡献、现金或服务水平，以及缺少目标、成本、库存年龄、归因或长期历史时的限制。
