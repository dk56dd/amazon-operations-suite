# 亚马逊 ABA 数据分析 Skill

## Skill 命名

| 项目 | 名称 |
|---|---|
| English name | `amazon-aba-analytics` |
| 中文名称 | `亚马逊ABA数据分析` |

## 使用目标

本 Skill 用于基于亚马逊 ABA 关键词数据，分析关键词市场周期、流量周期、竞争结构、前三 ASIN 垄断度、机会空间、广告打法和选品风险。分析必须以真实 ABA 数据或已连接的数据 MCP 为基础，不能用经验判断替代数据。

适用场景包括：

| 场景 | 需要回答的问题 | 典型输出 |
|---|---|---|
| 市场周期分析 | 关键词需求是在上升、下滑、季节性波动，还是短期异常？ | 周期阶段、风险、进入窗口 |
| 流量周期分析 | 流量是否集中在固定 ASIN，还是周期性轮动？ | 流量集中度、头部稳定性、轮动信号 |
| 垄断度分析 | 前三 ASIN 是否吃掉大部分点击和转化？ | 点击垄断、转化垄断、进入难度 |
| 竞品结构分析 | 谁拿点击，谁拿转化，谁只是曝光强？ | ASIN 分层、优势/劣势对比 |
| 广告与选品判断 | 是否值得打广告、进入、避开或差异化切入？ | 预算建议、关键词分组、动作优先级 |

## 开始前的数据准入

分析前先做准入检查。只有满足以下任一条件，才能继续：

| 准入方式 | 可继续条件 | 不满足时的动作 |
|---|---|---|
| 用户上传/提供 ABA 关键词数据 | 已有 Excel、CSV、数据库表、截图结构化数据，且包含关键词、时间或排名、点击份额、转化份额、前三 ASIN 字段中的主要字段 | 说明缺少哪些字段，请用户补齐 |
| `sorftime MCP` | 当前环境能通过 MCP 获取 ABA 或等价关键词数据 | 先调用 MCP 获取数据，再分析 |
| `卖家精灵 MCP` | 当前环境能通过 MCP 获取关键词、ABA、竞品或搜索词数据 | 先调用 MCP 获取数据，再分析 |

如果三个条件都不满足，停止分析并回复：

```text
当前还不能开始 ABA 分析。请先提供 ABA 关键词数据文件，或开启 sorftime MCP / 卖家精灵 MCP。需要的核心字段包括：关键词、时间周期、搜索频率排名、前三 ASIN、前三 ASIN 点击份额、前三 ASIN 转化份额。
```

不要在没有数据源时编造市场趋势、ASIN 份额、季节性或结论。

## 推荐输入字段

尽量识别不同导出版本的列名，不要因为列名略有差异就停止。可以把中文、英文和平台导出字段映射到统一字段。

| 标准字段 | 常见列名 | 用途 |
|---|---|---|
| `keyword` | 关键词、Search Term、Search Query | 分析对象 |
| `period` | 日期、周、月份、Reporting Range | 周期判断 |
| `search_frequency_rank` | 搜索频率排名、Search Frequency Rank、SFR | 需求热度代理指标，数值越小热度越高 |
| `asin_1` / `asin_2` / `asin_3` | Top Clicked ASIN #1/#2/#3 | 头部点击 ASIN |
| `click_share_1..3` | Click Share、点击份额 | 流量集中度 |
| `conversion_share_1..3` | Conversion Share、转化份额 | 成交集中度 |
| `category` | 类目、节点、Browse Node | 归类和横向比较 |
| `brand` | 品牌、Brand | 判断品牌垄断 |
| `price` | 价格、Price | 判断价格带竞争 |
| `rating` / `review_count` | 评分、评论数 | 判断转化壁垒 |

字段不足时仍可分析，但必须声明限制：

| 缺失字段 | 仍可做的分析 | 不能做的结论 |
|---|---|---|
| 缺少时间字段 | 单期竞争结构、垄断度快照 | 不能判断周期波动 |
| 缺少 SFR | 点击/转化集中度 | 不能判断整体搜索热度变化 |
| 缺少 ASIN | 关键词层面的集中度 | 不能判断具体竞品 |
| 缺少转化份额 | 点击垄断、流量结构 | 不能判断成交垄断 |
| 缺少点击份额 | 转化集中度 | 不能判断流量入口垄断 |

## 分析原则

1. 先清洗字段，再下结论。份额字段统一转成百分比数值，`12.5%` 和 `0.125` 都要识别。
2. ABA 的搜索频率排名是排名，不是搜索量。排名下降代表热度变差，排名上升到更小数字代表热度变强。
3. ABA 不能直接等同于广告点击、自然流量或真实销量。可以作为市场热度、点击集中和转化集中代理指标，但结论要标注“基于 ABA 代理指标”。
4. 涉及对比时使用表格，并同时说明优势和劣势。
5. 对数据展示也使用表格，必要时补充简短文字结论。
6. 如果需要落库、合并多期或搭建长期分析，默认使用 PostgreSQL。
7. 并发抓取或并发分析任务不能超过 5 个。
8. 不输出真实账号、Cookie、Token、MCP 密钥或其他凭证。

## 核心指标

### 前三 ASIN 点击份额总和

```text
Top3_Click_Share = click_share_1 + click_share_2 + click_share_3
```

含义：前三个 ASIN 吃掉的点击流量比例。数值越高，说明关键词点击入口越集中，广告和自然排名突破越难。

### 前三 ASIN 转化份额总和

```text
Top3_Conversion_Share = conversion_share_1 + conversion_share_2 + conversion_share_3
```

含义：前三个 ASIN 吃掉的成交转化比例。数值越高，说明用户购买选择越集中，头部 ASIN 的转化壁垒越强。

### 垄断度指数

基础版：

```text
Monopoly_Index = 0.5 * Top3_Click_Share + 0.5 * Top3_Conversion_Share
```

增强版在数据足够时使用：

```text
Monopoly_Index = 0.4 * Top3_Click_Share
               + 0.4 * Top3_Conversion_Share
               + 0.2 * Head_ASIN_Stability
```

`Head_ASIN_Stability` 用于衡量多期数据中前三 ASIN 是否长期不变。没有多期数据时，不使用增强版。

### 垄断度分级

| 垄断度指数 | 等级 | 市场含义 | 建议 |
|---:|---|---|---|
| 0%-30% | 分散 | 头部弱，长尾机会多 | 可测试进入，重点看转化效率 |
| 30%-45% | 轻度集中 | 有头部，但仍有替代空间 | 用差异化卖点和精准广告切入 |
| 45%-60% | 中度集中 | 头部已有明显优势 | 谨慎进入，先找细分词和价格带 |
| 60%-75% | 强集中 | 头部控制点击和转化 | 不建议正面硬打，优先找侧翼词 |
| 75%以上 | 高垄断 | 用户选择高度固化 | 除非有品牌、价格、供应链或产品创新优势，否则避开 |

## 点击份额与转化份额组合判断

| 点击份额总和 | 转化份额总和 | 结构判断 | 优势 | 劣势 | 动作建议 |
|---|---|---|---|---|---|
| 高 | 高 | 头部强垄断 | 用户认知稳定，头部模型清晰 | 新品突破成本高 | 避免正面硬打，找长尾词、场景词、功能差异词 |
| 高 | 低 | 流量被头部吸走，但转化不稳 | 有机会通过价格、评价、Listing 优化截流 | 点击成本可能高 | 广告先小预算测试转化缺口 |
| 低 | 高 | 点击分散但成交集中 | 有明确高转化竞品可学习 | 头部转化壁垒隐藏在产品力或评价里 | 拆解头部 ASIN 卖点、价格、评价和变体 |
| 低 | 低 | 市场分散 | 新进入机会较多 | 用户需求可能不稳定或关键词泛 | 做关键词分层，先验证精准词 |

## 市场周期波动分析

有多期数据时，按关键词和周期排序，分析以下变化：

| 指标 | 观察方式 | 结论方向 |
|---|---|---|
| SFR 趋势 | 排名是否持续变小或变大 | 变小代表热度增强，变大代表热度走弱 |
| SFR 波动率 | 多期排名标准差或环比变化 | 波动大说明需求不稳定，可能受促销、季节或事件影响 |
| 关键词覆盖 | 同类关键词数量变化 | 覆盖变多代表需求外溢或类目扩张 |
| 头部 ASIN 稳定性 | 前三 ASIN 是否频繁替换 | 替换频繁代表市场未固化 |
| 点击集中度变化 | Top3_Click_Share 环比变化 | 上升代表流量向头部集中 |
| 转化集中度变化 | Top3_Conversion_Share 环比变化 | 上升代表成交选择更集中 |

周期阶段判断：

| 阶段 | 数据特征 | 市场含义 | 优势 | 劣势 |
|---|---|---|---|---|
| 上升期 | SFR 持续变小，关键词覆盖增加，垄断度未明显上升 | 需求增长，仍有进入窗口 | 广告放量更容易拿增量 | 竞争会快速跟进 |
| 成熟期 | SFR 稳定，Top3 份额稳定，头部 ASIN 稳定 | 需求稳定，竞争结构清晰 | 可预测性强 | 新品突破成本高 |
| 衰退期 | SFR 持续变大，点击和转化都下降或集中到少数低价 ASIN | 需求走弱 | 可低成本捡漏 | 长期增长差 |
| 波动期 | SFR 和 Top3 份额频繁大幅变化 | 受季节、促销、热点或供给扰动影响 | 可抓短期窗口 | 库存和广告风险高 |

只有单期数据时，不要判断“周期”。应改为输出“当前市场结构快照”，并说明需要至少 4 个连续周期才能做基础趋势判断，最好有 8-12 个周期做稳定判断。

## 流量周期波动分析

流量周期重点看点击份额，而不是只看 SFR。分析时区分“需求热度变化”和“流量归属变化”。

| 分析项 | 计算或观察 | 说明 |
|---|---|---|
| 点击集中度趋势 | Top3_Click_Share 多期变化 | 判断流量是否越来越集中 |
| 头部 ASIN 轮动 | asin_1/2/3 多期变化 | 判断流量是否由固定竞品长期占据 |
| 第一 ASIN 领先优势 | click_share_1 - click_share_2 | 判断是否有单一 ASIN 强控流量 |
| 点击转化错配 | conversion_share_i / click_share_i | 判断 ASIN 是“高流量低转化”还是“低流量高转化” |
| 类目扩散 | 相似词头部 ASIN 是否一致 | 判断头部是否跨关键词控制流量 |

点击转化效率可用：

```text
Share_Efficiency_i = conversion_share_i / click_share_i
```

解释标准：

| Share_Efficiency | 判断 |
|---:|---|
| 大于 1.2 | 该 ASIN 转化效率强，成交能力高于点击占比 |
| 0.8-1.2 | 点击与转化基本匹配 |
| 小于 0.8 | 该 ASIN 吸引点击但成交效率偏弱 |

## 泛化分析模块

除用户明确要求的市场周期、流量周期、前三 ASIN 垄断度外，分析时保留约 50% 泛化空间，根据数据质量和业务目标选择以下模块：

| 模块 | 何时使用 | 输出 |
|---|---|---|
| 关键词分层 | 有多个关键词或词根 | 核心词、场景词、属性词、品牌词、长尾词 |
| 机会词筛选 | 垄断度低或转化错配明显 | 可切入关键词清单 |
| 风险词识别 | 垄断度高、品牌词明显、转化集中 | 避免或低预算测试关键词 |
| 竞品 ASIN 分层 | 有 ASIN 字段 | 流量型、转化型、垄断型、虚高型 |
| 产品力拆解 | 有价格、评分、评论数、图片或 Listing 信息 | 头部 ASIN 的优势/劣势 |
| 广告策略 | 用户关心投放 | 精准、词组、广泛、否词、预算分配 |
| 选品判断 | 用户关心进入市场 | 进入门槛、差异化方向、库存风险 |
| 数据异常检查 | 份额缺失、总和异常、周期断点 | 数据可信度和修正建议 |

## 推荐分析流程

按以下顺序执行：

1. 数据准入检查：确认有 ABA 文件、结构化数据、sorftime MCP 或卖家精灵 MCP。
2. 字段识别：把原始列名映射到标准字段。
3. 数据清洗：统一份额格式、时间格式、关键词大小写、空值和重复值。
4. 数据质量报告：说明样本周期、关键词数、ASIN 数、缺失字段、可分析范围。
5. 市场周期分析：基于 SFR、关键词覆盖、Top3 变化判断需求阶段。
6. 流量周期分析：基于点击份额、ASIN 轮动、第一名领先优势判断流量归属。
7. 垄断度分析：计算 Top3 点击份额总和、Top3 转化份额总和、垄断度指数。
8. 竞品结构分析：拆分流量型、转化型、垄断型、虚高型 ASIN。
9. 机会和风险判断：输出可打、谨慎、避开关键词。
10. 行动建议：分别给广告、Listing、选品和数据补充建议。

## 广告建议框架

广告建议要绑定 ABA 证据，不要只给通用投放话术。

| ABA 信号 | 广告判断 | 建议 |
|---|---|---|
| SFR 变小，Top3 垄断度低 | 增量窗口 | 精准匹配和词组匹配先放量 |
| SFR 稳定，Top3 垄断度高 | 成熟高壁垒 | 不正面硬抢大词，转向长尾和竞品 ASIN |
| 点击份额高、转化份额低 | 头部有转化漏洞 | 测试价格、优惠券、主图卖点截流 |
| 点击份额低、转化份额高 | 竞品成交效率强 | 优先研究 Listing、评价、价格和变体 |
| 第一 ASIN 领先极大 | 单品强控流量 | 竞品投放谨慎，先找替代场景词 |

## 选品建议框架

| ABA 信号 | 选品判断 | 建议 |
|---|---|---|
| 多个相关词上升，垄断度低 | 可进入 | 做差异化功能或套装，尽快验证 |
| 需求上升但转化垄断高 | 有需求但壁垒高 | 只有供应链、价格或产品创新明显时进入 |
| 需求下滑且点击集中 | 不优先进入 | 避免重库存，除非清仓或短期套利 |
| 流量轮动频繁 | 市场未固化 | 适合新品测试，但要控制预算和库存 |
| 品牌词占比高 | 品牌壁垒 | 不按普通泛词评估，单独剔除或标记 |

## 数据质量检查

分析时至少检查：

| 检查项 | 异常表现 | 处理方式 |
|---|---|---|
| 份额格式 | 百分比、小数混用 | 统一成 0-100 的百分比 |
| Top3 份额总和 | 超过 100% 或明显为 0 | 标记异常，回查原始数据 |
| 时间断点 | 周期不连续 | 周期分析降级为阶段性观察 |
| 关键词重复 | 同周期同关键词多行 | 合并或保留来源说明 |
| ASIN 缺失 | 有份额无 ASIN | 只能做集中度，不能做竞品拆解 |
| 品牌词混入 | 关键词含明显品牌名 | 单独分组，避免污染泛词判断 |

## PostgreSQL 长期分析建议

如果用户要工程化沉淀 ABA 数据，默认使用 PostgreSQL。建议表结构方向：

| 表 | 用途 | 核心字段 |
|---|---|---|
| `aba_keyword_snapshots` | 保存每期关键词数据 | keyword、period、sfr、category |
| `aba_top_asins` | 保存前三 ASIN 和份额 | keyword_id、rank_no、asin、click_share、conversion_share |
| `aba_keyword_metrics` | 保存计算结果 | top3_click_share、top3_conversion_share、monopoly_index、cycle_stage |
| `asin_profiles` | 保存竞品属性 | asin、brand、price、rating、review_count |

工程化注意事项：

1. 原始数据和计算结果分表保存，避免覆盖原始证据。
2. 每次导入记录来源、时间、文件名或 MCP 来源。
3. 关键词、周期、站点、类目建立唯一约束，避免重复导入。
4. 对份额、SFR、周期阶段保留计算版本，便于后续修正口径。

## 回复风格

输出必须中文、结论先行、证据紧跟。不要用泛泛而谈的运营建议。每个关键判断都要能追溯到 ABA 字段或数据质量限制。

当数据不足时，直接说明不能判断，不要为了完整报告强行推断。

优先使用这种表达：

```text
基于当前 ABA 数据，只能判断单期竞争结构，不能判断市场周期。当前关键词的前三 ASIN 点击份额总和为 68%，转化份额总和为 74%，垄断度指数为 71%，属于强集中。优势是头部模型清晰，劣势是新品正面突破成本高，建议优先找长尾词和转化错配词测试。
```

避免这种表达：

```text
这个市场很有潜力，建议加大广告投放。
```

## 失败处理

| 问题 | 正确处理 |
|---|---|
| 没有数据源 | 停止，要求用户提供 ABA 数据或开启 MCP |
| MCP 不可用 | 报告 MCP 不可用，并要求文件数据 |
| 只有截图 | 尽量结构化提取；无法提取时要求表格文件 |
| 只有单期数据 | 输出快照，不做周期判断 |
| 用户要求预测销量 | 说明 ABA 不等于销量，只能给代理判断 |
| 用户要求直接给结论但字段缺失 | 给可判断部分，并列出不能判断的部分 |

## 最小可交付标准

一次合格的 ABA 分析至少包含：

1. 数据来源和字段可用性。
2. 市场周期或“无法判断周期”的明确说明。
3. 流量周期或“无法判断流量周期”的明确说明。
4. Top3 点击份额总和。
5. Top3 转化份额总和。
6. 垄断度指数和分级。
7. 至少一张关键词或 ASIN 对比表，并包含优势和劣势。
8. 基于数据证据的广告、选品或运营建议。
9. 数据限制和下一步补数建议。
