# 供应链可行性评估 Skill

中文名称：供应链可行性评估  
English name: `supply-chain-feasibility-review`

## 使用目标

帮助用户判断产品方向是否具备供应链落地能力，识别低价陷阱、MOQ 压力、交期风险、质量风险和供应商改款能力。

## 触发场景

在以下情况使用本 skill：

- 用户找到产品方向后，想判断供应链能不能做。
- 用户提供 1688 链接、工厂报价、MOQ、打样信息，需要判断开发风险。
- 用户需要制定打样清单、质检清单或供应商筛选标准。

不适合使用本 skill 的情况：

- 用户没有供应商数据时，只能输出调研框架和待补字段。
- 用户只想做评论痛点分析，应使用 `review-painpoint-mining`。
- 用户只想做 Launch 预算，应使用 `new-product-launch-budget`。

## 必需输入

- `supplier_links`：供应商链接或店铺信息。
- `quotes`：报价。
- `moq`：起订量。
- `lead_time`：交期。
- `customization_type`：现货贴牌、轻改、结构改、开模、电控/认证改。
- `target_specs`：目标规格。
- `quality_requirements`：质量要求。
- `target_cost`：目标采购价。

## 可选数据源

- 1688 链接、供应商图片、规格表、质检报告、竞品参数。
- 用户指定需要开启 Sorftime MCP 时，先判断是否开启；未开启则要求用户提供供应商表或链接，不编造供应商数据。

## 数据要求

分析前先做数据完整性检查，并在输出开头写清“已满足 / 缺失 / 只能调研框架”。

| 数据项 | 最低要求 | 缺失时处理 |
|---|---|---|
| 供应商来源 | 1688 链接、供应商表、报价单或工厂资料 | 无供应商数据时只能输出调研框架 |
| 报价 | 单价、币种、是否含税/含包装/含配件 | 无报价不能判断目标采购价是否可达 |
| MOQ | 起订量和阶梯价 | 无 MOQ 不能判断首批现金流压力 |
| 交期 | 打样、量产、发货周期 | 无交期不能判断 Launch 节奏 |
| 材质和工艺 | 核心材质、结构、工艺、是否现货/私模/公模 | 无法判断开发难度 |
| 打样周期 | 打样费用、周期、可改项 | 无法输出落地时间线 |
| 目标规格 | 用户希望达到的尺寸、功能、质量要求 | 只能做供应商资料摘要 |
| 目标成本 | 利润模型中的采购价上限 | 不能判断报价是否可接受 |

供应商宣传图、店铺标题和口头承诺不能当作量产能力证明，必须要求样品、规格表或质检证据。

## MCP 开启约束

- 用户指定使用 Sorftime MCP 或其他供应链/竞品数据源时，必须先确认已开启。
- MCP 未开启时，不要编造供应商、报价、MOQ、销量、竞品参数或工厂能力；改为要求用户提供供应商表、1688 链接、报价单或截图。
- 1688 链接、供应商图片、规格表、质检报告来自不同口径时，要分开列出来源和置信度。
- MCP 或链接只能证明“看到的信息”，不能证明真实量产能力；量产能力必须通过打样、质检和交期验证。
- 如果供应商数据不足，结论必须降级为“需要更多数据”。

## 工作流

1. 先做数据完整性检查和 MCP/供应商来源检查；缺少供应商数据时只输出调研框架。
2. 整理供应商报价、MOQ、交期、材质、工艺、现货/私模/公模和打样周期。
3. 判断供应商类型：贸易商、源头工厂、组装厂、贴牌工厂。
4. 判断开发难度：现货贴牌、轻改、结构改、开模、电控/认证改。
5. 对比报价和 MOQ 是否符合利润模型和首批现金流承受能力。
6. 找质量风险点：材质、尺寸公差、耐用性、包装破损、说明书、配件漏装。
7. 输出打样要求、质检点、供应商筛选建议和不建议合作信号。

## 输出合同

用中文输出。供应商对比必须用表格，并同时说明优劣势。必须包含：

| 模块 | 必填内容 |
|---|---|
| 数据状态 | 已用供应商来源、MCP 是否开启、缺失字段、置信度 |
| 供应链可行性等级 | 可做、谨慎做、不建议、需要更多数据 |
| 供应商对比表 | 报价、MOQ、交期、工艺、改款能力、证书、优势、劣势 |
| 开发难度和时间线 | 打样、修改、开模、测试、量产、发货节点 |
| 目标采购价是否可达 | 当前报价与目标成本的差距 |
| 打样清单 | 规格、材质、尺寸、包装、配件、说明书、标签 |
| 质检清单 | 尺寸公差、耐用性、功能、包装跌落、配件完整性 |
| 不建议合作信号 | 低价异常、证书不匹配、交期模糊、MOQ 不合理、图片宣传替代实物能力 |
| 缺失输入 | 链接、报价、MOQ、交期、规格表、证书、样品图 |
| 下一步 skill | 利润测算、合规扫描或 Launch 预算 |

内部可使用统一字段：

```json
{
  "verdict": "go | cautious | no-go | need-more-data",
  "confidence": "high | medium | low",
  "key_findings": [],
  "risks": [],
  "action_items": [],
  "missing_inputs": [],
  "next_skill": ""
}
```

## 风险规则

- 不要只看低价，必须同时看交期、MOQ、质量稳定性和改款能力。
- 无供应商数据时，只能输出调研框架。
- 不要把供应商宣传图当作真实量产能力。
- 不要忽略认证、标签、包装和说明书对供应链的影响。
- 报价低于常识区间时，必须提示材质缩水、尺寸缩水、配件缺失或售后风险。

## 下一步

- 如果报价接近目标成本，进入 `profit-cost-estimator` 更新利润模型。
- 如果供应商需要证书或测试报告，进入 `compliance-certification-scanner`。
- 如果供应链可行且利润可行，进入 `new-product-launch-budget` 评估首月和 90 天预算。
